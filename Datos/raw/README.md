Datos RAW

Esta carpeta corresponde a los datos originales utilizados en el trabajo.

Los archivos CSV del dataset no se incluyen directamente en el repositorio debido a su tamaño. Los datos utilizados corresponden al dataset CICIDS2017 y fueron utilizados como entrada para las etapas de exploración, preprocesamiento y modelado.

Los archivos originales utilizados fueron:

* Monday-WorkingHours
* Tuesday-WorkingHours
* Wednesday-workingHours
* Thursday-WorkingHours-Morning-WebAttacks
* Thursday-WorkingHours-Afternoon-Infilteration
* Friday-WorkingHours-Morning
* Friday-WorkingHours-Afternoon-DDos
* Friday-WorkingHours-Afternoon-PortScan

Los mismos se pueden encontrar en https://www.kaggle.com/datasets/lucascalierno/cicids-2017
