\begin{frame}{¿Por qué detectar intrusiones?}

\begin{itemize}

    \item Las redes modernas generan grandes cantidades de tráfico continuamente.

    \item Entre ese tráfico puede existir actividad maliciosa, como ataques, escaneos, intentos de acceso no autorizado, entre otras.

    \item Un Sistema de Detección de Intrusiones (IDS) busca identificar automáticamente este comportamiento en tiempo real.

    \item El machine-learning permite automatizar esta tarea a partir de características extraídas del mismo tráfico de red.

\end{itemize}

\vspace{0.4cm}

\begin{block}{Objetivo}
Clasificar los tipos de tráficos utilizando modelos de machine-learning.
\end{block}

\end{frame}

%------------------------------------------------------------------------

El trabajo busca comparar dos enfoques:

\centering
\Large Random Forest
\end{block}

    \item Muy utilizado en datos tabulares.

\column{0.48\textwidth}

\begin{block}{Deep Learning}

\begin{itemize}

\end{itemize}

\end{columns}

\begin{block}{Pregunta}

\begin{frame}{Preprocesamiento: Tratamiento de variables predictoras}

Los datos fueron tratados previos al modelado. 

\begin{itemize}
    \item Se reportaron 308381 datos duplicados. Estos fueron eliminados para evitar malas lecturas.

    \item Se reportaron 353 valores faltantes. Los mismas fueron reemplazados por la respectiva media. Este método fue usado debido a que es simple y efectivo para datos numéricos. Además, se evitó eliminar posibles datos que podrían ser importantes.

    \item Se reportaron 3128 valores infinitos, tanto positivos como negativos. Se decidió quitar tales registros para evitar posibles errores.

    \item Se dividió el conjunto de datos en entrenamiento $(80\%)$ y prueba $(20\%)$

    \item Se estandarizó el conjunto de datos de entrenamiento, y luego se aplicó la transformación al conjunto de prueba

    \item Se evaluó la correlación, y se encontraron 34 variables con un coeficiente de correlación mayor a 0,85. En estos casos se eliminó una de las variables, para reducir redundancia
\end{itemize}

\end{frame}

\begin{frame}{Preprocesamiento: Tratamiento de variable objetivo}

El desbalance entre clases puede provocar errores en el modelado, y una baja detección de las clases minoritarias. Para abordar el problema del desbalance entre clases, se decidió aplicar SMOTE (Sinthetic Over-Sampling Technique).

Esta técnica genera nuevas observaciones sintéticas de las clases minoritarias a partir de las ya existentes. Esto permite aumentar la cantidad de observaciones, sin duplicar observaciones

El resultado es un dataset balanceado, con igual cantidad de observaciones en cada clase.

\vspace{0.2cm}

\begin{block}{Importante}
SMOTE se aplica sobre el conjunto de entrenamiento unicamente
\end{block}

\end{frame}

\begin{frame}{Random Forest: Marco teórico - Árboles de decisión}

Un árbol de decisión divide los datos mediante una secuencia de reglas hasta llegar a una predicción. Este realiza una serie de preguntas sobre una característica particular del dato, hasta llegar a una predicción

\begin{block}{Ventajas}

\begin{itemize}
    \item Son fáciles de interpretar.
    \item Pueden capturar relaciones no lineales.
    \item No requieren asumir una distribución específica de los datos.
\end{itemize}

\end{block}

\vspace{0.2cm}

\begin{alertblock}{Principal desventaja}
Los árboles de decisión presentan una varianza muy alta, pues pequeños cambios en los datos generan árboles muy distintos
\end{alertblock}

\end{frame}

%------------------------------------------------------------------------

\begin{frame}{Random Forest: Marco teórico - Idea general}

Para solucionar esto, se introduce el concepto de Random Forest

\begin{block}{¿Qué es Random Forest?}
Random Forest es un algoritmo de aprendizaje supervisado que combina múltiples árboles de decisión para realizar una predicción.
\end{block}

\begin{itemize}
    \item Cada árbol realiza una predicción de manera independiente.
    \item Los árboles se construyen utilizando diferentes muestras de los datos y subconjuntos de variables.
    \item Finalmente, se combinan las predicciones de todos los árboles.
\end{itemize}

\vspace{0.3cm}

La idea intuitiva es, un árbol puede equivocarse, muchos árboles a la vez es más raro. El modelo se vuelve más estable y robusto a los cambios. Para lograrlo, los árboles tienen que ser distintos entre sí.

\end{frame}

%------------------------------------------------------------------------
\begin{frame}{Random Forest: ventajas y limitaciones}

A continuación se presentan las principales ventajas y limitaciones de este método

\begin{columns}[T]

\column{0.48\textwidth}

\begin{block}{Ventajas}
\begin{itemize}
    \item Robusto frente a ruido y variaciones en los datos.
    \item Reduce la varianza respecto de un único árbol.
    \item Puede capturar relaciones no lineales.
    \item Requiere poca preparación de los datos.
    \item Difícil sobreajustarlo.
\end{itemize}
\end{block}

\column{0.48\textwidth}

\begin{alertblock}{Limitaciones}
\begin{itemize}
    \item Predicciones lentas en tiempo real debido a la cantidad de árboles
    \item Tiene un consumo de memoria elevado.
    \item Difícil de interpretar una predicción.
    \item Un bosque muy grande puede aumentar mucho el costo computacional.
\end{itemize}
\end{alertblock}

\end{columns}

\end{frame}

\begin{frame}{MLP: Marco teórico - Neuronas artificiales}

\begin{block}{¿Que es una neurona artificial?}
    Es una unidad de procesamiento que recibe entradas, las combina linealmente, suma un sesgo y aplica una función de activación para producir una salida.
\end{block}

Cada neurona realiza una transformación:

\begin{equation*}
    y = \sigma(z), \qquad \text{donde} \qquad z = \sum_i w_i x_i + b
\end{equation*}

\begin{itemize}
    \item $x_i$: valores de entrada.
    \item $w_i$: pesos de cada entrada. Indican la importancia de cada una.
    \item $b$: sesgo (bias). Permite ajustar el umbral.
    \item $\sigma$: función de activación. Decide si la neurona se "prende" o no
    \item $y$: salida de la neurona.
\end{itemize}
    
\end{frame}

%------------------------------------------------------------------------

\begin{frame}{MLP: Marco teórico - Idea general}

\begin{block}{¿Que es Multilayer Perceptron (MLP)?}
    Es una red neuronal, que organiza varias neuronas artificiales, y las apila en forma de capas
\end{block}

\vspace{0.3cm}

Las capas de neuronas se dividen en tres grupos:

\vspace{0.2cm}

\begin{itemize}
    \item Capa de entrada: Primera capa de neuronas que reciben los datos 
    \item Capas ocultas: Capas intermedias que procesan la información, y aprenden las relaciones mas complejas.
    \item Capa de salida: Capa final encargada de realizar la predicción.
\end{itemize}

\vspace{0.3cm}

Cada capa de neuronas aprende relaciones más complejas de los datos. Con suficientes capas, se puede aproximar cualquier función, sin importar su complejidad.
    
\end{frame}

%------------------------------------------------------------------------

\begin{frame}{MLP: Marco teórico - Ventajas y limitaciones}

A continuación, se presentan las principales ventajas y limitaciones de este método

\begin{columns}[T]

\column{0.48\textwidth}

\begin{block}{Ventajas}
\begin{itemize}
    \item Captura relaciones y patrones complejos entre las variables
    \item Permite ajustar su arquitectura como cantidad de capas y neuronas, para optimizar su rendimiento
    \item Es un modelo muy flexible, que se puede adaptar para muchos usos.
\end{itemize}
\end{block}

\column{0.48\textwidth}

\begin{alertblock}{Limitaciones}
\begin{itemize}
    \item Requiere ajuste de muchos hiperparámetros.
    \item Es fácil caer en un sobreajuste si el modelo es demasiado complejo en comparación a los datos
    \item Entrenamiento costoso computacionalmente.
    \item Muy dificil de explicar las predicciones realizadas.
\end{itemize}
\end{alertblock}

\end{columns}
    
\end{frame}

    \item Optimizador: Adam. Método basado en descenso por gradiente
    \item Capa de salida multiclase. Es la encargada de realizar las predicciones.
\end{itemize}

\begin{frame}{Análisis crítico: ¿Random Forest es mejor?}

Como hemos visto, el Random Forest, siendo un modelo de machine learning clásico, superó en términos de accuracy y F1-score al modelo MLP, siendo un modelo avanzado. Veamos las causas:

\vspace{0.3cm}

\begin{block}{¿Por qué puede ganar el Random Forest?}
    \begin{itemize}
        \item Datos tabulares: Random forest suele captar bien las relaciones no lineales de variables numéricas.
        \item Los múltiples árboles que particionan el espacio de variables permiten captar las interacciones entre características que pueden ser difíciles para un MLP.
        \item El MLP requiere mayor ajuste de hiperparámetros, lo que pudo verse afectado al no realizar una búsqueda exhaustiva.
        \item El desbalance entre clases afecta mucho el aprendizaje del MLP en las clases minoritarias
    \end{itemize}
\end{block}

\vspace{0.2cm}

Entonces, ¿podemos afirmar que el modelo Random Forest es mejor?

\end{frame}

%------------------------------------------------------------------------

\begin{frame}{Análisis crítico: ¿Cuando gana MLP?}

¿Cuando puede ganar el modelo MLP?

\begin{itemize}
    \item Datos con relaciones altamente no lineales, ya que las múltiples capas de neuronas pueden aprender funciones más complejas.
    \item Grandes volúmenes de datos, que aportan complejidad al modelo.
    \item Datos de alta dimensionalidad.
    \item Datos no tabulares, como datos con estructura espacial. Se especializa en relacionar imágenes o audios.
\end{itemize}

\end{frame}

%------------------------------------------------------------------------

\begin{frame}{Análisis Crítico: El rol del costo computacional }

Otro factor influyente en la elección de un modelo es el costo computacional. Existen varias razones para tenerlo en cuenta en el modelado de un sistema de detección de intrusión:

\begin{itemize}
    \item Tiempo de predicción: El modelo debe clasificar el flujo de red rápidamente, para poder actuar ante un ataque, antes de recibir daños o infiltraciones.
    \item Uso de recursos: El modelo mantener un costo computacional eficiente, debido a que tiene que mantener el funcionamiento a lo largo del tiempo.
    \item Volumen de tráfico: El modelo debe ser capaz de analizar grandes volúmenes de datos en tiempo real, sin acumular retrasos con la detección.
\end{itemize}

En nuestro problema, si bien Random Forest presenta mejores métricas, cada muestra debe recorrer múltiple árboles antes de tomar una decisión, lo que puede llevar a un mayor tiempo de detección. En este modelo, el entrenamiento tomó 9min y las predicciones tardaron 0,6 seg.

Por otro lado, si bien el modelo MLP suele ser más costoso de entrenar en términos de memoria, una vez entrenado, puede realizar las predicciones con mayor velocidad. En este modelo, el entrenamiento tomó 6min y las predicciones tardaron 0,4 seg.

\end{frame}

\begin{frame}{¿Cuando gana el aprendizaje profundo?}

\begin{block}{Veamos el siguiente paper: }
    Tang, W., \& Fei, Li. (2025). \textit{Handwritten digit recognition based on SVM}. In \textbf{Proceedings of the 2024 2nd International Conference on Frontiers of Intelligent Manufacturing and Automation (CFIMA ’24)} (pp. 324–331).
\end{block}

El paper trabaja sobre el dataset EMNIST, que es un conjunto de datos de imágenes en escala de grises de caracteres manuscritos, que incluyen tanto dígitos y letras en mayúscula y minúscula. El paper detalla las siguientes características en la sección 3.1:

\begin{itemize}
    \item Imagenes: escala de grises, de 28x28 pixeles.
    \item Variables: 784 valores de píxeles por cada imagen.
    \item Clases: 62 categorías, 10 dígitos, 26 mayúsculas y 26 minúsculas.
    \item Tamaño: 814 imágenes en total.
    \item Aplicación: reconocimiento y clasificación automática de caracteres manuscritos
\end{itemize}

    
\end{frame}

%------------------------------------------------------------------------

\begin{frame}{¿Cuando gana el aprendizaje profundo?}

El dataset, en la sección 4.2 compara varios modelos de machine learning, entre ellos compara el Random Forest con el MLP, y las métricas obtenidas fueron:

\vspace{0.4cm}

\begin{center}
    \begin{tabular}{c|c|c|c|c}
        \toprule
        Modelo & Accuracy (\%) & Precision (\%) & Recall (\%) & F1-score (\%) \\
        \midrule
        Random Forest & 64.7 & 69.5 & 62.3 & 65.7 \\
        MLP & 78.3 & 73.3 & 74.4 & 74\\
        \bottomrule
    \end{tabular}
\end{center}

Podemos observar que el modelo MLP obtiene mejores resultados que el modelo Random Forest. Esto sucede por diversas ventajas del MLP sobre el Random Forest, que incluyen:

\begin{itemize}
    \item Estructura espacial: los píxeles vecinos están relacionados y forman patrones locales, como bordes, trazos y curvas. 
    \item Alta dimensionalidad: cada imagen de 28 × 28 píxeles contiene 784 variables de entrada.
    \item Variables poco interpretables individualmente: el valor de un píxel aislado aporta poca información.
    \item Relaciones entre las variables complejas.
\end{itemize}

\end{frame}

\begin{frame}{Conclusiones finales}

Finalmente, analizando todas los resultados, tenemos lo siguiente para  elegir un modelo:

\begin{columns}[T]

\column{0.48\textwidth}

\begin{block}{Ventajas RF}
\begin{itemize}
    \item Mejor accuracy, precision y F1-score.
    \item Menor cantidad de falsas alarmas.
    \item Se puede ajustar el umbral de decisión.
\end{itemize}
\end{block}

\column{0.48\textwidth}

\begin{block}{Ventajas MLP}
\begin{itemize}
    \item Mayor recall.
    \item Menor cantidad de ataques no detectados.
    \item Menor tiempo de entrenamiento.
    \item Menor tiempo de predicción.
\end{itemize}
\end{block}

\end{columns}

\vspace{0.4cm}

Teniendo en cuenta que el modelo MLP deja pasar menor cantidad de ataques, y actúa con mayor velocidad que el Random Forest, considero que puede ser una mejor alternativa a la hora de elegir un modelo de detección de intrusión en redes.
